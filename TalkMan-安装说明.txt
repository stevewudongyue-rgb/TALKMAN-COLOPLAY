TALKMAN COLOPLAY 0.1.28.61

运行 TalkMan.exe。首次使用请在设置中完成语音服务、COLOPLAY 连接和目标窗口配置。
已有用户覆盖安装时，用户目录中的 API Key、草稿和配对设置不会被安装器清空。
61：小屏 T.M. 下显示卡带号；设置 → COLOPLAY 可核对实际版本。长按旋钮 0.5 秒后松开填入。Wi-Fi 卡带同时按住右上、右下、左下 5 秒，检查并安装配对电脑附带的新卡带，提前松开取消。首次须手动安装本机配对 61 卡带；纯 USB 仍手动更新。真实设备更新待实机验收。
包含 60 的 Windows 高缩放、多屏绿框坐标修复。
通用更新卡带随桌面安装包附带，不含配对信息；设备保留本机配对。桌面一键升级不直接替换旧设备卡带。初次从设置导出配对源码并编译安装后，才可三键更新。
Windows 已知 ChatGPT／Codex 主框默认恢复核验后的二次发送，其它位置可在选择时勾选“此位置用回车发送”。填入成功且核验通过后，五秒内短按左上发送；未勾选时仍只填入。正常改标题不再使位置失效；控件真正消失会引导重选，不会自动重复粘贴。

便携版请保留 TalkMan.exe 与 _internal 文件夹在同一目录。
