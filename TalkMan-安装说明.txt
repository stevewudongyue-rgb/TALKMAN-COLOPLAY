TALKMAN COLOPLAY 0.1.28.64

运行 TalkMan.exe。首次使用请在设置中完成语音服务、COLOPLAY 连接和目标窗口配置。
已有用户覆盖安装时，用户目录中的 API Key、草稿和配对设置不会被安装器清空。
64：应用已认可的圆屏四键图标与顶部组合 Logo，统一桌面快捷方式、窗口与任务栏。AI 整理意外返回空内容时保留正文；填入前可恢复同一窗口内唯一可识别的失效主输入框；选择输入位置时主窗口让开，确认或取消后恢复。本次为 Windows 本机安装，Mac64 尚待验证，公开更新仍为63。沿用62卡带。
63：补同步 Mac 设置独立窗口修复，不再被系统合并为主窗口标签页；切页不改变设置外框，保留主窗口形状、正文和选区。沿用62卡带，无需更新ROM。
62：平时小屏不显示卡带号，只在三键更新倒计时内显示；设置 → COLOPLAY 仍可核对实际版本。长按旋钮 0.5 秒后松开填入。Wi-Fi 卡带同时按住右上、右下、左下 5 秒，检查并安装配对电脑附带的新卡带，提前松开取消。61 及以上支持此手势；更早版本需先手动安装本机配对 62 卡带，纯 USB 仍手动更新。真实设备跨版本更新待实机验收。
公司 M2 Mac 使用 Apple 芯片版（macOS 14 及以上）。先升级公司电脑，再更新与公司电脑配对的卡带；不要使用家中电脑的配对卡带。
包含 60 的 Windows 高缩放、多屏绿框坐标修复。
通用更新卡带随桌面安装包附带，不含配对信息；设备保留本机配对。桌面一键升级不直接替换旧设备卡带。初次从设置导出配对源码并编译安装后，才可三键更新。
Windows 已知 ChatGPT／Codex 主框默认恢复核验后的二次发送，其它位置可在选择时勾选“此位置用回车发送”。填入成功且核验通过后，五秒内短按左上发送；未勾选时仍只填入。正常改标题不再使位置失效；控件真正消失会引导重选，不会自动重复粘贴。

便携版请保留 TalkMan.exe 与 _internal 文件夹在同一目录。
